Deleting careers and custom databases

To delete one career, open Load career and tap the cross next to it. To delete a custom database, open it under New career › Custom database and tap Remove this file from the folder. Uninstalling the game deletes everything, including your settings and club styles.

Custom databases you import

If you start a career with your own database, the game reads the file you pick on your phone (or copy into its Databases folder) and keeps a copy in its own storage. The file is read only on your phone and is never uploaded.

Databases from a web address (only when you ask)

If you use Load from a web address on the Custom database screen, the game downloads the one address you typed or pasted, when you tap Download. Like any website, that server sees your phone's IP address and the standard details of the game's web client. The game sends nothing else: no account, cookie or identifier. The file is saved only on your phone.

Nothing else

Apart from what this policy describes, the game doesn't send or download anything: it plays offline and needs no account. (Settings › Privacy policy › Open the online version opens this page in your phone's browser.)
