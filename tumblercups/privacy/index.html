Difficulty settings download

When the game starts, it downloads a small settings file from this website (iterum.games/tumblercups/tuning.json) so we can adjust how hard new levels are without an app update. The request carries no ID, account or game data. Like any website, our host (GitHub Pages) sees your IP address and app version in its server logs, which it uses to run and secure the service. We don't receive or keep those logs.

Sharing your daily result

If you tap Share result, the game opens your phone's share menu with a short text (your moves, boosters and streak). Nothing is shared unless you pick an app and send it.
