Feedback you send us

If you write a message in {{ page.feedback.path }} and tap Send, we receive:

  • your message (please don't include personal details such as your name or email);
  • the game version and build, {{ page.feedback.context }}, your device's platform and operating system version, and its language setting;
  • a random player ID that Unity creates when you send feedback, so we can tell messages from the same player apart and delete them if you ask.

Messages are stored with Unity Gaming Services (Cloud Save) where only we can read them, used only to improve the game, and kept for up to 12 months. To have your messages deleted, email us with roughly when you sent them.
